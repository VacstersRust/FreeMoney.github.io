# скамятТУТ.ру — сатирический интерактивный лендинг

Полностью статический адаптивный сайт на HTML, CSS и JavaScript. Никакого сервера, базы данных, платежей, аналитики или сбора персональных данных нет.

## Запуск

Откройте `index.html` в браузере. Для локального сервера (при наличии Python):

```powershell
py -m http.server 5500
```

Затем откройте `http://localhost:5500`.

## Что работает

- Адаптивная навигация (в том числе мобильное меню)
- Анимации элементов, VIP-карточки и бегущей строки
- CTA и карточки программ открывают сатирическое модальное окно
- Колесо шуточных предсказаний с анимацией
- Калькулятор «доверчивости»
- Шуточный таймер (зациклен и прямо отмечен как таковой)
- Пародийные всплывающие уведомления с маркировкой
- Поддержка `prefers-reduced-motion`, клавиатурной навигации, `dialog`

## Примечание

Внешний Google Fonts используется только для шрифтов. При отсутствии подключения работает системный fallback. Домен в логотипе — идея/брендинг, регистрация и публикация на домене не выполнялись.

Сайт — пародия. Никаких реальных курсов, гарантированного заработка, платежей и форм для сбора контактных данных.
